# Химия карточек (связи соседей)

Заменяет старую «плоскую» химию — `(самый частый клуб − 1) × 2 + (самая частая страна − 1) × 1`
к силе всего состава — на связи между соседними слотами схемы (в стиле FIFA). Включается флагом
`GameConfig.chemistry_enabled` (по умолчанию **выключено** — тогда всё считается по-старому байт-в-байт).

Код: `backend/app/services/chemistry_service.py` (чистые функции), клиентское зеркало
`frontend/src/lib/chemistry.ts`, общий фикстур `frontend/src/test/chemistryCases.json`
(его проверяют и pytest, и vitest; пересоздаётся `python -m scripts.gen_chemistry_cases`).

## Правила

| Что | Формула | Настройка GameConfig (по умолчанию) |
|---|---|---|
| Связь соседей | один клуб **и** одна страна — сильная, клуб **или** страна — средняя, иначе нет | `chemistry_link_strong` (2), `chemistry_link_medium` (1) |
| Соседство | серверная таблица `FORMATION_LINKS` для 4-3-3, 4-4-2, 3-5-2, 5-3-2 | — |
| Химия игрока 0–3 | на своей позиции (`position == ideal_position` слота): число порогов, которых достигла сумма его связей, но не меньше «пола»; не на своей позиции — 0 | `chemistry_threshold_1/2/3` (1/2/4), `chemistry_player_floor` (0), `chemistry_player_max` (3) |
| Бонус в матче | очки × прибавка; не на своей позиции — минус штраф; рейтинг в матче держится в 1..99 | `chemistry_rating_per_point` (1), `chemistry_off_position_penalty` (0) |
| Химия команды | сумма химии игроков, «N из 3 × слотов» | — |
| Тренер-земляк | игрок на своей позиции из страны тренера (`Coach.country`) — + очки химии, не выше максимума | `chemistry_coach_country_points` (1) |
| Домашний стадион | игрок на своей позиции из клуба стадиона (`Stadium.club`) — + очки химии, не выше максимума; **только там, где действует сам стадион**: в турнирах — только хозяин поля, в Card Arena — всегда | `chemistry_stadium_club_points` (1) |

Страна тренера и клуб стадиона задаются в админке (миграция 0140), пусто = бонуса нет; турниры,
зафиксировавшие правила до появления этих бонусов, играют без них. Редакторы составов показывают
химию как для домашнего матча (с бонусом стадиона). Пустые клуб/страна не связываются; клуб/страна сравниваются с нормализацией пробелов (как
`clean_group_key`). Рейтинг на самой карточке не меняется — бонус есть только в матче.

## Где действует и порядок применения

* **Card Arena** (`lineup_service._serialize_lineup`, `match_service`): рейтинг карты (+ диамант) →
  **+ химия (≤ 99)** → позиция/редкость/тактика → тренер (бонус по редкости) → стадион. Средние
  рейтинги линий для моментов матча (`_category_avg`) тоже с химией. Сила и рейтинги замораживаются в
  матче на старте (`Match.user_team_strength`, `server_state.ratings`, для аудита — `server_state.chemistry`).
* **Турниры игроков** (`player_tournament_simulation_service._build_side`): рейтинг (+ диамант) →
  **+ химия** → профиль зон → бусты тренера → стадион. Правила химии **фиксируются при старте
  турнира** (`player_tournaments.chemistry_rules`, NULL = выключено) — включение/перенастройка
  флага не меняет уже идущие турниры. Применённая химия пишется в `skill_snapshot.chemistry` матча.
* **Навыки карточек** — отдельные броски на событие, рейтинг не читают: двойного учёта нет.
* Старая плоская химия при включённом флаге **не добавляется** (нет двойного учёта).
* **FUT Draft** — остаётся на своей формуле (группы клуба/страны + встроенная плоская химия): там
  пики раздаются с весами под размер групп, очки идут в лидерборд и должны быть сравнимы между
  драфтами, начатый драфт не должен менять правила. Подсказки `_chemistry_hints` теперь показывают и
  встроенную часть — сумма «+N» в подсказках равна фактическому вкладу химии в силу (есть тест).
* **Клубы** (`club_squad_service._lineup_to_out`, `tournament_simulation_service.apply_chemistry`):
  рейтинг ClubCard → **+ химия (≤ 99)** → профиль зон → бусты тренера → тренировка/стадион. Химия
  считается по реально вышедшему составу (с заменами; незаполненный слот — без связей). Правила
  **фиксируются при старте клубного турнира** (`tournaments.chemistry_rules`, миграция 0139, NULL =
  выключено). «Сила» и тактическое соответствие в редакторе — с химией; средние по линиям — чистые
  рейтинги карточек. «Лига клубов» считается по активности, составы в ней не участвуют.
* **Редакторы турнирных составов** (клуб, турнир игроков): химия показывается по правилам, по которым
  будет сыгран следующий матч — у идущего турнира это его зафиксированные правила
  (`ChemistryOut.frozen = true`, плюс `live_enabled`), и редактор пишет об этом.
* **«Собрать лучший состав»** (`auto_squad_service.improve_for_chemistry`): при включённой химии
  жадный подбор дополняется ограниченным локальным поиском (замены со скамейки — лучшие по рейтингу и
  связанные с соседями, перестановки между слотами), цель — (игроков на своей позиции, сила с
  химией). Лимит бриллиантов, блокировки и «копировать из Арены» соблюдаются. Подсказки «+N» со
  скамейки по-прежнему по рейтингу.
* Карьера, Тактико, Стратего — не затронуты.

## API

* `LineupOut.chemistry`, `PersonalSquadOut.chemistry` (`ChemistryOut`): `enabled`, `team`, `team_max`,
  `links[{a,b,level,points}]`, `players[{slot_code,points,link_sum,on_position,rating_bonus}]`,
  `adjacency`, `rules`, `strength_bonus` (сколько химия даёт к показанной силе; при выключенном
  флаге — старый плоский бонус). Поле добавочное — старые клиенты его игнорируют.
* `POST /api/v1/lineups/chemistry/preview` `{formation, slots:[{slot_code,user_card_id}]}` —
  химия гипотетической расстановки своих карт без сохранения.

## Подбор стартовых значений

`python -m scripts.compare_chemistry --synthetic 2000` (только чтение) — сила существующих составов
по старой и новой формуле, распределение разницы, доля пар составов, поменявшихся местами.

# Stadiums Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add "Stadiums" — a new collectible card entity like Coaches, but simpler: each stadium is just a flat admin-configurable strength-boost percentage. Stadiums drop from packs the same way coaches do (personal and club packs), are owned the same way (personal + club card tables), and are equipped in a squad the same way (a picker slot next to the coach slot) — in the personal Lineup (Card Arena), the Club squad, and the Player Tournament squad.

**Architecture:** A near-exact structural mirror of the existing Coach system, with one deliberate simplification: `Coach` has a child `CoachBoost` table (multiple typed, rarity-gated boosts); `Stadium` has a single `boost_pct` column instead — no child table, no boost-count-by-rarity validation. Everywhere else (pack drop coin-flip, dual ownership — `UserStadiumCard`/`ClubStadiumCard` — admin CRUD + image upload, squad equip slot), the shape is copied field-for-field from the Coach implementation.

**Tech Stack:** Python 3.12 (test venv: 3.14), FastAPI, async SQLAlchemy 2, Alembic, pytest; React 18 + TypeScript + Vite + TanStack Query.

**Spec:** Approved in chat on 2026-09-28. No separate spec file — this plan is authoritative, built directly against the Coach implementation already in this codebase (`backend/app/models/coach.py`, `user_coach_card.py`, `club_coach_card.py`, `schemas/coach.py`, `services/coach_service.py`, `routers/admin_coaches.py`, `services/pack_service.py`, `services/club_pack_service.py`, `frontend/src/admin/pages/AdminCoachesPage.tsx`, `frontend/src/components/cards/UserCoachCardPickerModal.tsx`, `frontend/src/components/clubs/ClubCoachCardPickerModal.tsx`) — read verbatim by this plan's author before every task below was written.

## Global Constraints

- New Alembic revision `0121`, `down_revision = "0120"` (current head on this branch).
- `Stadium.boost_pct` is a `Numeric(5, 4)` fraction (e.g. `0.0500` = +5%), admin-settable, no fixed tiers — unlike Coach, there is no boost-count-by-rarity rule to enforce.
- `Stadium` excludes diamond rarity, mirroring `Coach`'s `CheckConstraint("rarity != 'diamond'")`.
- Reuse the existing `CardSource` enum for `UserStadiumCard.source` (already has a generic `pack` value, exactly as `UserCoachCard` does) and the existing `ClubCoachCardSource`-shaped pattern for a new `ClubStadiumCardSource` enum (mirrors it exactly: values `club_pack`, `admin_grant`).
- Pack drop: `Pack.stadium_drop_chance` / `ClubPack.stadium_drop_chance`, same independent-per-slot coin-flip mechanism as `coach_drop_chance`, same diamond exclusion (`rarity != Rarity.diamond`). A pack slot resolves to a player, a coach, OR a stadium — never more than one — so the coin flips must be checked in a fixed order (coach first, then stadium) with each flip only consuming the "this slot is not a player" branch once. See Task 2 for the exact control flow.
- `PackOpeningCard`/`ClubPackOpeningCard` gain a third nullable FK (`user_stadium_card_id`/`club_stadium_card_id`) and their CHECK constraints become three-way "exactly one of the three" instead of "exactly one of two".
- The strength boost is applied identically to how a coach's `training_multiplier`-style effect already flows through `lineup_service.calculate_base_strength` and `club_tactical_profile_service.compute_profile` — both functions gain a new `stadium_multiplier: float = 1.0` parameter, applied as a further multiplication alongside the existing `training_multiplier` (default `1.0`, i.e. no behavior change for a squad with no stadium equipped). Every existing call site keeps working unchanged because the parameter defaults to `1.0`.
- Squad screens in scope: personal Lineup (Card Arena, `lineup_service.py` / `ArenaPage.tsx`), Club squad (`club_squad_service.py` / `ClubSquadPage.tsx`), Player Tournament squad (`personal_squad_service.py` / `PlayerTournamentSquadPage.tsx`). Tactico is explicitly OUT of scope — it has no coach slot today, and gets no stadium slot either.
- In each squad UI, the stadium slot sits to the right of the coach slot (both inside the "GK row" corner area where the coach button already floats) — mirror the coach button's exact styling/position, offset to the other side.
- Reuse `formatGameError`/`ApiRequestError`, design tokens, and the existing admin-page conventions (`Page<T>` pagination, `log_action` audit trail) — no new patterns.

async def get_stadium_or_404(db: AsyncSession, stadium_id: int) -> Stadium:

async def create_stadium(db: AsyncSession, payload: StadiumCreate) -> Stadium:

async def update_stadium(db: AsyncSession, stadium_id: int, payload: StadiumUpdate) -> Stadium:
    stadium = await get_stadium_or_404(db, stadium_id)
    updates = payload.model_dump(exclude_unset=True)

        setattr(stadium, key, value)
    db.add(stadium)
    await db.flush()
    return stadium

async def save_stadium_image(upload: UploadFile, rarity: Rarity, display_name: str) -> str:
    """Validates and stores an uploaded stadium image; returns the DB-stored relative path."""
    if not upload.filename or "." not in upload.filename:
        raise AppError("invalid_file", "File has no extension", 400)

    extension = upload.filename.rsplit(".", 1)[-1].lower()
    if extension not in ALLOWED_EXTENSIONS:
        raise AppError("invalid_file_type", f"Extension .{extension} is not allowed", 400)
    if upload.content_type and upload.content_type not in ALLOWED_CONTENT_TYPES:
        raise AppError("invalid_file_type", f"Content-Type {upload.content_type} is not allowed", 400)

    contents = await upload.read()
    if len(contents) > MAX_UPLOAD_BYTES:
        raise AppError("file_too_large", f"File exceeds {MAX_UPLOAD_BYTES // (1024 * 1024)}MB limit", 400)
    if len(contents) == 0:
        raise AppError("invalid_file", "Uploaded file is empty", 400)

    target_dir = STADIUMS_DIR / rarity.value
    target_dir.mkdir(parents=True, exist_ok=True)

    filename = _sanitize_filename(display_name, extension)
    target_path = target_dir / filename
    target_path.write_bytes(contents)

    return f"stadiums/{rarity.value}/{filename}"


def delete_stadium_image(relative_path: str | None) -> None:
    if not relative_path:
        return
    full_path = (STATIC_DIR / relative_path).resolve()
    if STATIC_DIR.resolve() in full_path.parents and full_path.is_file():
        full_path.unlink(missing_ok=True)

router = APIRouter(prefix="/admin/stadiums", tags=["admin"], dependencies=[Depends(get_current_admin)])


@router.get("", response_model=Page[StadiumOut])
async def list_all_stadiums(
    search: Optional[str] = None,
    include_inactive: bool = True,
    params: PageParams = Depends(),
    db: AsyncSession = Depends(get_db),
):
    query = select(Stadium)
    count_query = select(func.count(Stadium.id))
    if not include_inactive:
        query = query.where(Stadium.is_active.is_(True))
        count_query = count_query.where(Stadium.is_active.is_(True))
    if search:
        query = query.where(Stadium.display_name.ilike(f"%{search}%"))
        count_query = count_query.where(Stadium.display_name.ilike(f"%{search}%"))

    total = (await db.execute(count_query)).scalar_one()
    query = query.order_by(Stadium.id.desc()).offset(params.offset).limit(params.page_size)
    stadiums = (await db.execute(query)).scalars().all()
    return Page.build([StadiumOut.model_validate(s) for s in stadiums], total, params)

@router.delete("/{stadium_id}")
async def delete_stadium(stadium_id: int, request: Request, db: AsyncSession = Depends(get_db), admin: User = Depends(get_current_admin)):
    stadium = await get_stadium_or_404(db, stadium_id)
    user_card_count = (
        await db.execute(select(func.count(UserStadiumCard.id)).where(UserStadiumCard.stadium_id == stadium_id))
    ).scalar_one()
    club_card_count = (
        await db.execute(select(func.count(ClubStadiumCard.id)).where(ClubStadiumCard.stadium_id == stadium_id))
    ).scalar_one()
    card_count = user_card_count + club_card_count
    if card_count > 0:
        raise ConflictError(
            f"Cannot delete: {card_count} card instance(s) reference this stadium. Deactivate it instead.",
            details={"user_card_count": user_card_count, "club_card_count": club_card_count},
        )
    await log_action(
        db, admin.id, "delete_stadium", "stadium", stadium_id, old_value={"display_name": stadium.display_name},
        ip_address=request.client.host if request.client else None,

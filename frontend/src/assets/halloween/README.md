# «🎃 Ночь тыкв» — картинки ивента

Положи сюда файлы с этими именами (.webp или .png) — они заменят нарисованные
заглушки без правок кода (`src/lib/halloween.ts`, `halloweenArt`):

| Файл | Где | Размер |
| --- | --- | --- |
| `banner.webp` | плашка на главной и шапка страницы ивента | 1200×400 |
| `pack.webp` | пак «Ночь живых Легенд» в лавке и блоке коллекции | 600×800 |
| `door-1.webp`, `door-2.webp`, `door-3.webp` | три двери «Кошелёк или жизнь» | 360×600 |
| `frame-zombie.webp`, `frame-vampire.webp` | рамка поверх карточки коллекции (прозрачная середина) | 600×800 |
| `badge.webp` | значок «Тыква 2026» в лавке | 256×256 |

Босс «Безголовый вратарь»: `src/assets/bosses/kontra-headless.webp` (384×384).
Картинку значка для профиля загрузи в админке «Значки» (значок «Тыква 2026»),
картинку пака — в админке «Паки».

# «💯 Нам 100 дней!» art

Drop files here (`.webp` preferred, `.png` works) — they replace the drawn
placeholders without code changes (`lib/anniversary.ts`, `anniversaryArt`):

| file | where | size |
| --- | --- | --- |
| `banner` | home banner and the page header | 1200×560 |
| `recap-bg` | background of the «Мои 100 дней» story | 1080×1920 |
| `gift` | a closed gift tile of the calendar | 256×256, transparent |
| `gift-final` | the last (7th) gift tile | 256×256, transparent |
| `badge-100` | the «100 дней» badge picture | 256×256, transparent |

Cards of «Первые 100» take the gold `gold100` frame from CSS (`index.css`).
